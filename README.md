 # 🍏 Apple Sales & Profit Performance Dashboard (Power BI)

## 📌 Overview
This project presents an interactive Power BI dashboard designed to analyze Apple product sales, order quantities, profitability, and regional distribution performance. The dashboard enables data-driven decision-making by surfacing top-performing regions, profitability curves based on order quantity, and return rates.

---

## 📊 Business Key Performance Indicators (KPIs)

* **Total Sales:** $1.57M
* **Total Quantity Sold:** 22K units
* **Total Product Count (IDs):** 5.901K
* **Total Profit:** $175.26K

---

## 🚀 Key Insights & Dashboard Features

1. **Regional Breakdown:**
   * **West Region** accounts for the highest share of profit and volume, outperforming East, Central, and South regions.
2. **Profitability vs. Quantity Analysis:**
   * Higher order quantity does not linearly scale profit; peak profit points occur at specific quantity threshold clusters.
3. **Returns Analysis:**
   * Tracking order delivery fulfillment shows **5.6K completed shipments** versus **0.3K returned items**, keeping returns under control.
4. **Detailed Transactional Table:**
   * Interactive tabular breakdown displaying city, year, quarter, month, day, region, individual sales value, and profit margins.
